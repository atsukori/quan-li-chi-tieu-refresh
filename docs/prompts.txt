• Hãy thực hiện các yêu cầu sau:
1. Đề xuất cấu trúc thư mục dự án:
- Hãy thiết kế và trình bày một cấu trúc thư mục chuẩn, tối ưu cho mô hình Flask (MVC / App Factory) sao cho khoa học, dễ bảo trì, dễ mở rộng tính năng và thuận tiện cho việc commit lên GitHub.

- Viết nội dung file README.md thật chi tiết, bao gồm: Giới thiệu dự án, các tính năng chính, mô tả cơ sở dữ liệu, hướng dẫn cài đặt môi trường (Python 3.11, venv), cách khởi chạy trên localhost và hướng dẫn deploy lên server sau này.

- Giao diện HTML (Jinja2) sử dụng Bootstrap 5 đẹp mắt, trực quan.

Hướng dẫn các bước chạy lệnh cụ thể trên Windows (cmd/PowerShell) để khởi tạo CSDL (seed data) và chạy server.
